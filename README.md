# ece445-cardshufflerproj


Automatic card shuffler built using:
- ESP32
- Servo motors
- Stepper motor (+ driver)
- IR sensors
- Linear actuator (+ driver)

## Features
- Automatic card detection
- Stateful shuffling system
- Tray extension mechanism
- Interactive encoder-controlled stepper mode pulley system
